AI-Based Exam Proctoring System

Computer vision application for exam monitoring
Academic project
PythonOpenCVYOLOv8
LIVE
face
gaze →
phone
Illustration

A computer-vision application designed to support exam monitoring by detecting faces, gaze direction and mobile phones, with image captures for later review.

  • Face detection — checks that the candidate is present in front of the camera
  • Gaze direction — estimates whether the candidate is looking away from the screen
  • Mobile phone detection — YOLOv8 object detection on the video frames
  • Image captures — saved with a timestamp when an event is flagged

Detection workflow

  1. Capture webcam frames with OpenCV
  2. Detect the face and estimate gaze direction
  3. Run YOLOv8 to detect mobile phones
  4. Flag events of interest (e.g. face out of frame, looking away, phone visible)
  5. Save a timestamped image capture
  6. A human reviewer checks the captures

Technical architecture

Webcam input OpenCV · frame processing Face & gaze analysis YOLOv8 · phone detection Event flagging Image captures for review

Limitations

  • Accuracy depends on lighting, camera quality and angle
  • Gaze estimation is approximate
  • False positives and missed detections are possible
  • A single camera cannot see what happens off-screen
  • Captures involve personal data: consent and secure storage are required

Detections are indicators for human review, not proof of misconduct. Every flagged event must be checked by a person before any decision is made.
